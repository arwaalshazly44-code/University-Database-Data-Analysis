# University-Database-Data-Analysis
University database and data analysis project using SQL Server and Excel.
<img width="1200" height="1200" alt="university-logo" src="https://github.com/user-attachments/assets/8470a354-0955-432a-a9e3-99fbb2f31795" />

## Project Overview

This project combines **SQL Server and Excel** to build and analyze a University Database System.

The project covers the complete workflow from **database design and SQL analysis to Excel data modeling and dashboard creation**.

### Project Workflow

**Database Design → SQL Server → Data Insertion → SQL Reports → Power Pivot → PivotTables → KPIs → Dashboard**

---

## 1. SQL Server

The database was designed and implemented using **SQL Server** based on the university requirements.

The SQL part includes:

* Database and table creation.
* Primary keys and foreign keys.
* Relationships between tables.
* Sample data insertion.
* Stored procedures for different reports.
* Database relationship diagram.

📁 **[View SQL Project](./SQL/README.md)**

---

## 2. Excel Analysis

The data was then analyzed in **Excel using Power Pivot and PivotTables**.

The Excel part includes:

* Power Pivot data model.
* KPIs.
* PivotTable analysis.
* Charts.
* Interactive dashboard.

📁 **[View Excel Analysis](./Excel/README.md)**

---

## Key KPIs

The dashboard includes:

* **Total Students**
* **Total Courses**
* **Total Instructors**
* **Average Salary**
